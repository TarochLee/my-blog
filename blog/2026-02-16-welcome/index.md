欢迎来到我的个人博客。

这里主要记录技术学习、开发实践以及日常思考内容。博客基于 **Docusaurus** 构建，用于整理长期积累的知识，并形成可持续更新的技术笔记体系。

## 关于这个博客

这个站点采用 Docusaurus 搭建，属于静态网站架构。文章以 Markdown 形式编写，通过构建生成静态页面，再由服务器提供访问。这种方式结构清晰，维护成本较低，也方便版本管理。

博客内容将逐步覆盖以下方向：

- C++ 开发与工程实践
- 智能汽车与软件系统相关技术
- Linux 与服务器部署记录
- 编程工具与效率提升
- 一些与音乐制作相关的经验

## 写作方式

所有文章都存放在项目的 `blog` 目录中，通过 Git 进行版本管理。每一次更新都会生成新的静态页面并部署到服务器。

这种流程带来的好处包括：

- 内容可追溯
- 修改记录清晰
- 部署过程稳定可控
